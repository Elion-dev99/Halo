# Halo → NetSuite 相当 機能ロードマップ

NetSuite 会計相当を目標に、モジュール単位で実装する。

## 完了済み
- 総勘定元帳（GL）: 科目、期間、仕訳、試算表、PL、BS、元帳
- アプリシェル、認証、組織ブートストラップ
- **設定画面**（組織 / アカウント / メンバー / 機能）をサイドメニューに追加
- **組織 RBAC**（owner / admin / accountant / viewer）+ Firestore ロール別ルール
- **売掛（AR）**: 顧客、売上請求書、確定時の自動仕訳、入金消込
- **買掛（AP）**: 仕入先、買掛請求、確定時の自動仕訳、支払消込

## 次イテレーション
- 銀行口座・明細照合
- 税金コード / 消費税（仮受・仮払）の分離計上
- 承認ワークフロー
- 予算 vs 実績
- 固定資産・減価償却
- 在庫・原価
- 多通貨
- 子会社・連結
- 高度な経営レポート / ダッシュボード KPI
- 監査ログの本格化

> 「NetSuite と同じものを一度に全部」は現実的ではないため、会計コア → AR/AP → 周辺モジュールの順で埋めます。
