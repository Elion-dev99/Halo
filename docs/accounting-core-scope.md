# Halo 会計コア — スコープ定義

## 第1到達目標（Stage 0〜4）

NetSuite 相当を長期目標としつつ、**最初の完成定義**は次の会計コアに限定する。

| 機能 | 内容 | 実装 Stage |
|------|------|------------|
| 認証 | メール/パスワード登録・ログイン・ログアウト | 1 |
| 組織 | 登録時に組織 1 件作成、メンバー紐付け | 1–2 |
| アプリシェル | サイドナビ + コンテンツ領域 | 1 |
| 会計期間 | 作成、オープン、クローズ | 2 |
| 勘定科目 | CRUD、階層、有効/無効、初期科目セット | 2 |
| 仕訳 | 複数借方/貸方、下書き、転記、取消 | 3 |
| 仕訳一覧 | 期間・ステータス・科目フィルタ | 3 |
| 総勘定元帳 | 科目別・期間別明細と残高推移 | 4 |
| 試算表 | 期間指定 | 4 |
| 損益計算書 | 期間指定 | 4 |
| 貸借対照表 | 期末時点、貸借一致検算表示 | 4 |
| エクスポート | CSV またはブラウザ印刷 | 4 |

## Out of Scope（Stage 0〜4 ではやらない）

| 領域 | 理由 |
|------|------|
| 売掛・買掛（請求・入金・支払） | Stage 5+ 別 Plan |
| 顧客 / 仕入先マスタ本格管理 | AP/AR とセット |
| 在庫・購買・販売 | ERP 拡張 |
| 固定資産・減価償却 | モジュール後続 |
| 税計算・税効果・電子帳簿詳細 | 後続 |
| 多通貨・多子会社・連結 | 後続 |
| 予算・承認ワークフロー | 後続 |
| 監査ログの本格実装 | 最小の createdBy 等のみ |
| モバイルアプリ | README 将来項目 |
| 課金プラン（light/standard/...） | 会計コアと無関係。旧 plan.html は廃止 |
| PDF 帳票の本格レイアウト | CSV/印刷で代替 |
| 旧 Firestore データの自動移行 | 破壊的改修として新モデルのみ |
| NetSuite 全モジュール UI の再現 | ナビ骨格のみ参考 |

## 用語集（日本語 UI）

| 用語 | 英字キー | 説明 |
|------|----------|------|
| 組織 | organization | 会計単位となる会社 |
| 会計期間 | period | 仕訳を束ねる期間。クローズ可能 |
| 勘定科目 | account | 資産/負債/純資産/収益/費用 |
| 仕訳 | journal | 複式記入のヘッダ |
| 仕訳明細 | journal line | 借方または貸方の 1 行 |
| 下書き | draft | 未転記 |
| 転記 | posted | 元帳・レポート集計対象 |
| 取消 | void | 集計対象外 |
| 総勘定元帳 | general ledger | 科目別の取引履歴 |
| 試算表 | trial balance | 全科目の借方・貸方集計 |
| 損益計算書 | income statement | 収益・費用・当期純利益 |
| 貸借対照表 | balance sheet | 資産・負債・純資産 |

## 受け入れ条件（Stage 4 完了時）

1. 新規ユーザーが登録し、組織・初期科目・会計期間が揃う
2. 複数行の複式仕訳を入力し、転記できる
3. クローズした期間に転記できない
4. 転記済仕訳から試算表・PL・BS・総勘定元帳が一致して表示される
5. サンプル取引（例: 資本金払込 → 売上・経費 → 試算）で手計算と一致する

## 確認（Stage 0）

本ドキュメントの In/Out、画面一覧、用語、受け入れ条件に合意できたら **Stage 0 OK**。
