# Halo 会計コア全面改修 — 作業マークダウン

## 確定方針

| 項目 | 内容 |
|------|------|
| 第1到達目標 | 会計コア（勘定科目・仕訳・総勘定元帳・試算表・PL/BS・会計期間） |
| 技術スタック | React（Vite + TypeScript）+ Firebase Auth + Firestore |
| 進め方 | 各 Stage 完了後に利用者確認。**OK が出るまで次 Stage に進まない** |

## 作業ルール

1. 段階開始前に「この段階でやること」を短く提示する
2. 実装・文書化が終わったら確認用サマリを出す
3. 利用者が **OK** と明示するまで次段階の実装に入らない
4. NG / 修正指摘があれば同段階内で修正し、再度確認を取る
5. 本ファイルのステータスを更新する

## 段階ステータス

| Stage | 名称 | ステータス | 備考 |
|-------|------|------------|------|
| 0 | 改修方針・情報設計の固定 | 完了 | 2026-07-30 OK |
| 1 | プロジェクト土台（React + Firebase） | 完了 | 2026-07-30 OK |
| 2 | 組織・会計期間・勘定科目マスタ | 完了 | 確認省略指示により継続 |
| 3 | 仕訳入力・一覧・転記 | 完了 | 確認省略指示により継続 |
| 4 | 総勘定元帳・財務諸表 | **確認待ち** | Stage 3 連続実装。第1到達目標 |
| 5+ | AP/AR 等（別 Plan） | 範囲外 | Stage 4 OK 後に別途起票 |

ステータス値: `未着手` / `作業中` / `確認待ち` / `完了`

## Stage 0 — 改修方針・情報設計の固定

**目的**: 会計コアの用語・画面・データモデル・権限の骨格を合意する

**成果物**:

- [docs/WORKPLAN.md](WORKPLAN.md)（本ファイル）
- [docs/architecture.md](architecture.md)
- [docs/data-model.md](data-model.md)
- [docs/accounting-core-scope.md](accounting-core-scope.md)

**確認ポイント**:

- スコープ境界（In / Out of Scope）
- 組織単位マルチテナント
- 勘定科目タイプ・正規残高
- 仕訳ステータス（draft / posted / void）
- 会計期間クローズの扱い

**ゲート**: 利用者 OK → Stage 1 へ

---

## Stage 1 — プロジェクト土台（React + Firebase）

**目的**: 動く空シェルを確立する

**予定作業**:

- Vite + React + React Router + TypeScript
- Firebase 初期化を `VITE_FIREBASE_*` に統一
- 認証画面（ログイン / 登録）、アプリシェル（NetSuite 風サイドナビ骨格）
- Firestore Security Rules 初版
- 旧 Vanilla HTML / JS の削除またはリダイレクト方針の確定・実施

**ゲート**: 利用者 OK → Stage 2 へ

---

## Stage 2 — 組織・会計期間・勘定科目マスタ

**目的**: 会計の前提マスタを UI + Firestore で完成させる

**予定作業**:

- 登録時に組織を 1 つ作成
- 会計期間の作成・オープン / クローズ
- 勘定科目 CRUD、階層、有効/無効、標準科目セット初期投入
- 一覧・検索・バリデーション（コード重複禁止など）

**ゲート**: 利用者 OK → Stage 3 へ

---

## Stage 3 — 仕訳入力・一覧・転記

**目的**: 複式簿記の中核トランザクションを正しく扱う

**予定作業**:

- 複数借方・複数貸方、下書き / 転記 / 取消（void）
- 貸借一致バリデーション
- クローズ期間への転記禁止
- 仕訳一覧（期間・ステータス・科目フィルタ）
- 残高は転記済仕訳の集計を正とする（科目ドキュメントへの naive 加減算はしない）

**ゲート**: 利用者 OK → Stage 4 へ

---

## Stage 4 — 総勘定元帳・財務諸表

**目的**: 会計コア第1到達目標を満たす

**予定作業**:

- 総勘定元帳、試算表、損益計算書、貸借対照表
- 期間切替、CSV または簡易印刷（PDF は後続）

**ゲート**: 利用者 OK = 会計コア第1到達目標完了
